# Rare Username Hunter — Samsung Android

Private, user-operated research tool for four-letter collectible Telegram usernames on Fragment.

**Build status:** GitHub Actions creates a debug APK for testing. This is not a username-claiming bot. Listings may show UNKNOWN when Fragment blocks automation; no availability or profit is guaranteed.

## APK
Visit the [Actions builds](https://github.com/muneebranjha10/Username/actions) and download the `RareUsernameHunter-debug-apk` artifact from a successful run. The ZIP contains `app-debug.apk`.

## Safety
Only enter Telegram credentials into a build you trust; never share an API hash, session file, login code, password, or TON wallet recovery phrase. App sign-in uses your own Telegram API ID and hash. Usernames must be verified on [Fragment](https://fragment.com/). No automatic bidding, purchasing, or username transfers.

Source code is bootstrapped by the setup workflow. Build is **not verified** until the Actions run passes.
